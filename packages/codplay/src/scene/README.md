# Scene

> Status: En cours
> CodPlay version: V2 foundation

This folder owns the authoring-side scene model and the build boundary.

- `SceneDoc` and authoring contracts
- build, validation, normalization, and diagnostics
- resource and requirement derivation
- function extraction and scene-oriented exports

The scene layer does not depend on the engine or the player.

The serializable playback artifact lives in `compiled/`.
