# Elcé

Elcé is the métier application that will author Elcé documents and project
their pages through CodPlay and Sighty. The package is intentionally at its
initial application stage: the controller and the three work areas are present,
while the document model is added in the next construction tranche.

Run the application from the repository root:

```sh
npm run dev --workspace=@codplay/elce
```

The workspace also exposes `typecheck`, `test`, `build`, and `preview` scripts.
