# Chronomètre

> Statut : En cours
> Version CodPlay : V2 foundation

Cette démo porte `chrono-story.ts` dans la scène V2. Les commandes Démarrer,
Pause, Reprendre et Réinitialiser déclenchent des événements discrets ;
l'aiguille et l'affichage sont interpolés par `TweenAction` sur la timeline.
Pause et Reprendre contrôlent le chronomètre de la scène et ne suspendent pas
la lecture du player.

Elle est accessible depuis le sélecteur des démos V2 avec `?demo=chrono`.
