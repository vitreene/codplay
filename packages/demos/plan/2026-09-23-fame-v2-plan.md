# Page Fame V2 — plan

## Statut et périmètre

Statut : `En cours`. La route V1 est conservée sous `fame-v1.html` et la page
`fame.html` présente la sélection V2 ordonnée confirmée par l'utilisateur. La
validation du parcours réel dans le navigateur reste à effectuer.

Ce plan ne modifie aucun contrat ni code du runtime CodPlay. La page utilise le
layout V2 et les définitions déjà enregistrées dans le registry V2.

## Décisions retenues

- `fame-v1.html` conserve l'entrée V1 actuellement servie par `fame.html` ; ses
  liens de navigation restent sur cette route.
- `fame.html` devient l'entrée V2 de la sélection Fame.
- La sélection contient dix démos V2, dans cet ordre : `components`, `events`,
  `position`, `quiz-series`, `polygon`, `preload-media`, `chrono`,
  `threejs-grid`, `rive`, puis la fixture expérimentale non normative
  `stroke-path`.
- `avatar`, `flip-list` (`FLIP stress test`) et `flip-nested` sont exclus de la
  page Fame. La démo `flip-nested` reste disponible sur la page complète.
- Les options du sélecteur suivent l'ordre explicite des identifiants retenus.
- Les deux pages V2 passent par le même layout et le même point d'entrée ; la
  page Fame ne duplique ni scène, ni player, ni télécommande, ni journal.
- Le comportement d'interaction de ce layout est défini par le
  [contrat du layout V2](../specs/v2-demo-layout-spec.md) et suivi dans le
  [plan de verrou d'entrée](./2026-09-23-v2-layout-launch-gate-plan.md).
- La page V2 complète reste sur le parcours `index.html`.

## Travaux

1. Déplacer l'entrée V1 et ses liens de navigation vers `fame-v1.html`.
2. Faire posséder le balisage partagé par `src/v2/layout/` et le réutiliser sur
   les entrées V2.
3. Ajouter la sélection Fame ordonnée à partir du registry V2.
4. Documenter le contrat stable et le suivi de la page.

## Critères d'acceptation

- Le build multi-page produit `index.html`, `fame.html` et `fame-v1.html`.
- Les liens de la page V1 restent sur `fame-v1.html` et sélectionnent la bonne
  démo V1.
- La sélection V2 contient exactement les dix démos documentées dans cet
  ordre ; elle exclut Avatar, FLIP stress test et `flip-nested`.
- Le sélecteur des deux entrées V2 utilise le même layout. Un changement de
  sélection conserve la page courante et charge la scène depuis le registry
  partagé.
- Le parcours réel de chaque entrée V2 est validé dans le navigateur avant de
  marquer ce travail terminé.

## Suivi d'implémentation

- L'ordre des neuf démos a été confirmé le 2026-09-23.
- `stroke-path` a été ajoutée en fin de sélection le 2026-09-24.
- La page V2 et la migration de route V1 sont implémentées ; la validation
  navigateur complète reste ouverte.
